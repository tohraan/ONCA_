## 🚀 Features

### Multi-Step Onboarding
- **AI Personalization** - Tailored dashboard based on user role (Founder, Finance Manager, Operations, Explorer)
- **Business Context Collection** - Industry, country, and company size configuration
- **Intent Selection** - Focus areas including cash flow, compliance, expenses, and AI insights
- **Data Connection** - Bank account, accounting tool, or CSV upload integration
- **First AI Win** - Immediate value demonstration with cost-saving opportunities

### Comprehensive Dashboard
- **Real-time Activity Tracking** - Visual representation of daily financial activities
- **AI Finance Copilot** - Interactive chat assistant for financial queries
- **Net Flow Summary** - Weekly performance charts with projections
- **To-Do List** - Task management for financial obligations

### AI-Powered Insights
- **Burn Analysis** - Intelligent cost optimization recommendations
- **Expense Heatmap** - Visual breakdown by category (Payroll, Software, Marketing, Rent)
- **Financial Metrics** - Total spend, cash runway, and risk assessment
- **AI Forecasting** - Predictive revenue modeling with 94% accuracy

### Expense Management
- **Transaction Tracking** - Comprehensive list with categorization
- **Receipt Scanning** - Camera integration for quick expense capture
- **CSV Import** - Bulk transaction upload capability
- **Status Filtering** - Approved, flagged, and review states

### Cash Flow Analysis
- **Inflow vs Outflow Charts** - Visual comparison of money movement
- **Projected Balance** - Future liquidity forecasting
- **Real-time Monitoring** - Live updates from connected data sources

### Compliance & Tax
- **Filing Checklist** - Automated reminders for GST, income tax, and payroll
- **Audit Score** - Real-time compliance health monitoring (98% score)
- **Certificate Downloads** - Instant access to compliance documentation

## 🛠️ Technology Stack

- **Frontend Framework**: React 19 with TypeScript
- **Build Tool**: Vite 5.0
- **Styling**: Tailwind CSS (CDN)
- **Charts**: Recharts 2.10
- **Icons**: Material Icons Round
- **Fonts**: Plus Jakarta Sans, Inter

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/tohraann/onca-portal-.git
cd onca-portal-

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will open at [http://localhost:5173](http://localhost:5173)

## 🏗️ Build for Production

```bash
# Create production build
npm run build

# Preview production build
npm run preview
```

## 🔄 User Flow

1. **Initial Dashboard** (4.5s) - Animated loading with progress bar
2. **Onboarding** (6 steps) - Role selection → Business context → Intent → Data connection → AI win → Confirmation
3. **Portal Dashboard** - Main interface with 5 navigable views:
   - Dashboard (Home)
   - Insights (AI Analysis)
   - Expenses (Transactions)
   - Cash Flow (Charts)
   - Compliance (Tax & Audit)
